Sales Analytics Project | End-to-End Data Analysis Using Python

I recently completed a data analytics project focused on understanding monthly revenue trends, product performance, and customer behavior using Python. This project allowed me to apply core analytical techniques and build actionable insights from raw sales data.

Key Technical Work Performed:

1. Data Cleaning & Preprocessing -
- Parsed and standardized date formats
- Corrected data types
- Extracted month, city, and product-level information

2. Exploratory Data Analysis (EDA) -
- Analyzed monthly total revenue using line charts
- Identified top revenue-generating products
- Examined city-wise sales distribution and order patterns
- Created a combined line + stacked bar chart showing total revenue vs.  product contribution for every month

3. Feature Engineering -
- Created custom metrics like revenue labels (Lakh/Million format)
- Converted months to ordered categorical data for accurate sorting
- Generated month & product level aggregated datasets

4. Visualization & Insights -
- Used Plotly, Seaborn, and Matplotlib for interactive and static charts
- Highlighted the highest contributing product for each month
- Compared trends across months to identify peak periods and low-performing phases
- Built clean visual summaries suitable for dashboards or reports

Insights Identified:

- Clear revenue seasonality across months
- Specific products consistently dominated revenue in key months
- Noticeable variation in performance across different cities
- Customer purchasing patterns indicated strong peaks around certain time periods

This project helped me strengthen my skills in:
Python (Pandas, Seaborn & Plotly), Data Cleaning, EDA, Visualization, and Analytical Storytelling.
